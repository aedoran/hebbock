## How to read this
- **Canonical Name** — the one true name to use everywhere.
- **Slug** — the kebab-case filename (without the folder).
- **Aliases** — every variant spelling I've seen; any of these should resolve to the canonical.
- **Type** — pc / party / npc / location / faction / item / creature / arc / session / worldbuilding / campaign
- **Page** — the wiki-link to the full page (world entities under `hebbock/`, campaign entities under `campaigns/<slug>/`).
